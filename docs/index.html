The Build Log — Producer

Open-source tools behind the YouTube channel The Build Log: a pipeline that turns a script into a finished MP4 on an 8 GB GPU (local voice, word alignment, diagrams, captions), plus a small publisher that uploads and schedules videos to the channel's own YouTube account.
