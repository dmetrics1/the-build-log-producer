Privacy Policy

The Build Log Publisher · Last updated: 17 November 2026

What this app is

The Build Log Publisher is a private tool used only by the owner of the YouTube channel The Build Log to upload, schedule and caption the channel's own videos and to read the channel's own analytics. It is not offered to other users.

Data the app accesses

With the channel owner's consent, the app uses the YouTube API Services to: upload videos, set titles, descriptions, thumbnails and captions, schedule publication, and read view and subscriber statistics of the owner's own channel. It does not access data of any other YouTube user.

How data is stored and used

OAuth tokens and channel statistics are stored only on the owner's computer and are used only to publish and measure the channel's own videos. Nothing is sold, shared with third parties, or used for advertising.

Retention and deletion

Tokens are kept until access is revoked. Revoking access deletes the stored token from the owner's computer within 7 days; you can revoke access at any time at Google Account permissions.

Google and YouTube policies

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
